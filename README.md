# RETVec Online

Standalone browser demo using the RETVec v1 JavaScript model from Google Research.

## Run locally

Because browsers normally block local model loading from `file://`, serve this folder with a static HTTP server:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy online

Upload the contents of this folder to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any static web host.

No Python backend is required for the web app itself.
